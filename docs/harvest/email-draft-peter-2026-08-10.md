Would it be possible for the documented option to return the actual track count, or is there another batch endpoint you would recommend?

Your previous response, Roland, clarified multilingual search and keyword groups, but did not cover these two operators specifically. Would it be possible for these operators to support those three matching modes? If they are already supported, could you please share the precise payload for each mode?
